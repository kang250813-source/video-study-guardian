# 视频学习守护 · Android 版

孩子在抖音、快手、B站、西瓜、腾讯视频、爱奇艺、优酷、芒果TV、YouTube 等视频 App 里**累计观看**满设定的分钟数（默认 10 分钟）后，屏幕会被全屏答题界面盖住：

- 答对一题：解锁，重新计时；
- 答错：多加一题，并显示正确答案、等待 3 秒再换题；
- 家长输入密码可直接解锁。

题目与电脑版共用仓库根目录的 `bank/` 题库（构建时自动打包进 APK），按年级（1–6）、上/下册、科目、专题模式（全部 / 背古诗 / 背单词）、英语教材版本出题，规则与电脑版一致。应用不需要联网权限，不收集任何数据；家长密码以 PBKDF2-SHA256 加盐哈希保存在手机本地。

系统要求：Android 8.0（API 26）及以上。

## 一、下载安装

1. 打开本仓库的 **Releases** 页面下载 `VideoStudyGuardian.apk`；或在 **Actions → Android APK** 里选最近一次成功的运行，下载 `VideoStudyGuardian` 压缩包并解压。
2. 把 APK 传到孩子的手机上点击安装。系统提示“未知来源”时，按提示允许本次安装（OPPO 可能会要求输入账号密码或提示“风险应用”，选择“继续安装”）。
3. 打开“视频学习守护”，完成**首次设置**：两次输入家长密码（至少 6 位）、每轮分钟数、年级、上/下册。

> 没有配置正式签名密钥时，CI 生成的 APK 使用调试签名，每次构建的签名可能不同。若安装新版本时提示“签名不一致”，请先卸载旧版本再安装（设置会丢失，需要重新设置）。想要能直接覆盖升级，见文末“正式签名”。

## 二、授予权限（必须）

首次设置后进入“家长设置”，最上方的权限列表全部变成 ✅ 才能正常工作：

| 权限 | 用途 | 怎么开 |
| --- | --- | --- |
| 使用情况访问 | 识别当前正在用的 App，只在视频 App 前台时计时 | 点“去开启” → 在列表里找到“视频学习守护” → 允许 |
| 显示在其他应用上层（悬浮窗） | 时间到后显示全屏答题界面 | 点“去开启” → 打开开关 |
| 通知 | 常驻通知显示本轮剩余时间，保持服务运行 | 点“去开启” → 允许 |
| 忽略电池优化 | 防止系统省电时杀掉守护服务 | 点“去开启” → 允许 |

设置好后可以点“立即测试答题界面”试一下。

## 三、OPPO / 一加 / realme（ColorOS）额外设置

ColorOS 会积极清理后台，不设置的话守护服务可能被关掉：

1. **自启动**：设置 → 应用 → 自启动管理（部分版本在“手机管家 → 权限隐私 → 自启动管理”），打开“视频学习守护”。家长设置页里的“自启动管理”按钮会尝试直接跳过去。
2. **后台运行**：设置 → 电池 → 应用耗电管理 → 视频学习守护，打开“允许后台运行”“允许自启动”“允许关联启动”，关闭“智能限制后台运行”。
3. **锁定卡片**：打开最近任务，把“视频学习守护”的卡片下拉加锁，避免“一键清理”时被关闭。
4. 悬浮窗权限在 ColorOS 里叫“悬浮窗”或“显示在其他应用上层”，位于 设置 → 应用 → 应用管理 → 视频学习守护 → 权限。

其他品牌（小米、华为、vivo 等）也有类似的“自启动 / 后台运行 / 省电策略”设置，请同样放开。

## 四、家长设置

- 每轮观看分钟数（1–60）、暂停守护（暂停期间不计时、不出题，答题中会立即解锁）。
- 年级、上/下册、科目、专题模式、英语教材版本（新教材没有对应题库时自动用旧教材）。
- 视频 App 列表：可从本机已安装的应用里勾选或取消，也可恢复默认列表。
- 修改家长密码。离开家长页后再次进入需要重新输入密码。
- 开机后服务会自动启动（需要允许自启动）。

## 五、限制与建议

- 本应用不是安全软件。懂手机的孩子可能在系统设置里**关闭权限、强行停止或直接卸载**本应用；Android 普通应用无法阻止这些操作。
- 建议同时使用系统自带的保护功能：**家长守护 / 儿童空间 / 应用锁**（ColorOS：设置 → 健康使用手机 / 儿童空间；或 手机管家 → 应用锁），给“设置”“应用商店”“文件管理”加锁，并关闭孩子的安装权限。也可以使用 Google 的 Family Link。
- 计时依赖系统的“使用情况访问”数据，只在屏幕亮着、已解锁、视频 App 在前台时计时；画中画小窗或后台播放音频不计时。
- 答题界面会请求音频焦点，大多数视频 App 会因此自动暂停；个别 App 可能继续播放声音。
- 答题界面盖住全部应用并屏蔽返回键，但无法屏蔽系统的主页/最近任务手势；按主页键后答题界面仍会留在最上层。

## 六、自己编译

需要 JDK 17、Android SDK（platform 34）和 Gradle 8.7：

```bash
cd android
gradle assembleRelease        # 或 assembleDebug
# 生成的 APK：app/build/outputs/apk/release/app-release.apk
```

构建时会把仓库根目录的 `bank/*/*.json` 复制进 APK 的 `assets/bank/`，修改题库后重新构建即可。

### 正式签名（可选）

在本地生成一次密钥库（请妥善保管，丢失后无法覆盖升级）：

```bash
keytool -genkeypair -v -keystore release.jks -alias guardian -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.jks   # 复制输出
```

在 GitHub 仓库 Settings → Secrets and variables → Actions 中添加：`ANDROID_KEYSTORE_BASE64`（上面的 base64 内容）、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD`。之后 CI 会用它签名；未配置时自动退回调试签名。**不要把密钥库或密码提交进仓库。**
